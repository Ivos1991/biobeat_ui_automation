# Home Assignment Checklist

## Concept Overview

Use this checklist to build a senior-level automation assignment quickly and systematically.

## Why It Matters

Assignments are short on time. A checklist prevents obvious architectural omissions.

## Core Principles

- Start with structure
- Keep scope realistic
- Show extensibility intentionally

## Recommended Implementation Patterns

- Build runtime and settings early
- Add one clear extension seam
- Keep at least one API and one UI example thin and polished

## Common Mistakes

- overengineering the first pass
- leaving CI or docs to the end
- writing tests before framework seams exist

## Examples From This Project

- DI container
- hooks and plugins
- orchestrator-backed tests
- CI quality gates

## Reusable Templates

1. Set repository structure.
2. Add typed settings.
3. Add runtime bootstrap and DI.
4. Add API base client and services.
5. Add UI base page and actions.
6. Add evidence and reporting.
7. Add CI and docs.

## Interview Explanations

The checklist proves you can deliver under time pressure without sacrificing architecture.

## Best Practices Checklist

- repo structure is intentional
- config is typed
- tests are deterministic
- CI exists
- docs exist
